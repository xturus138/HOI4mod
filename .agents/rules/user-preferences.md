# User Preferences & Working Rules

1. **Do Not Auto-Install**:
   - Never copy or install mod files to `Documents/Paradox Interactive/Hearts of Iron IV/mod` without explicit user confirmation ("Jangan pasang dulu").

2. **Language Rules**:
   - All story, event descriptions, event choices, focus descriptions, and decisions are written in standard HOI4 English.
   - Strictly preserve all essential Indonesian historical, military, institutional, and cultural loanwords (*Volksraad*, *KNIL*, *TKR*, *TII*, *Proklamasi*, *Merdeka*, *KMB*, *ORI*, *Majapahit*, *Pusaka*, *Dewan Adat*, *Ulama*, *Syariat*, *Negara Islam Indonesia*, *Front Rakyat*, *Gotong Royong*, *Pancasila*, etc.).

3. **Character Persona & Style**:
   - Ultra-terse, telegraphic, maximum compression.
   - Format: `[thing] [action] [reason]. [next step].`
   - Use Indonesian for conversational replies to user.
   - Clickable file links using `file://` scheme.
